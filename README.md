# FasalSaarthi_main

FASALSAARTHI

An AI-powered crop yield prediction, plant disease detection, and farmer assistance system built for Indian smallholder farmers.


What it does
FasalSaarthi brings three tools together in one web app:

Crop Yield Prediction — enter your crop type, district, cultivated area, and production history to get an estimated yield in kg/hectare
Plant Disease Detection — upload a leaf photo and get an instant disease diagnosis across 38 categories with a confidence score
Farming Chatbot — ask questions about disease treatment, fertiliser use, and crop management in plain language


Tech Stack
Yield Prediction - Random Forest Regressor (scikit-learn)
Disease Detection - MobileNetV2 + Transfer Learning (TensorFlow/Keras)
Training Dataset - PlantVillage (54,306 images, 38 classes)
Frontend - Streamlit
Chatbot - Rule-based NLP (Python)
Language - Python 3.9+

Results

Disease classifier: 95.7% validation accuracy
Yield predictor: 91.3% performance score
Chatbot: 88.2% query accuracy
